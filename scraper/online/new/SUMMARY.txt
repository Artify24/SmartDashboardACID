🎯 WHAT THIS PACKAGE DOES
═══════════════════════════════════════════════════════════════════════════════

INPUT: Website URL
   ↓
PROCESSING:
   ├─ Loads website with Chrome + Selenium
   ├─ Triggers dynamic content loading
   ├─ Extracts comprehensive business data:
   │  ├─ Company info (title, description)
   │  ├─ Pricing plans & features
   │  ├─ Call-to-action buttons
   │  ├─ Social media links
   │  ├─ Integrations & partners
   │  ├─ Trust signals (testimonials, certifications)
   │  ├─ Page structure (headings)
   │  └─ Internal links
   ├─ Discovers internal pages
   ├─ Recursively scrapes up to N pages
   ├─ Aggregates and deduplicates data
   └─ Generates reports
   ↓
OUTPUT: 
   ├─ business_data.json (structured data)
   └─ business_intelligence_report.txt (formatted summary)

────────────────────────────────────
$ python -m main https://example.com --headless --max-pages 15

METHOD 2️⃣  - PYTHON SCRIPT
────────────────────────────────────
from scraper import AdvancedBusinessScraper

with AdvancedBusinessScraper(headless=True) as scraper:
    data = scraper.scrape_website("https://example.com", max_pages=8)
    print(scraper.get_analysis_report(data))

METHOD 3️⃣  - IMPORT AS LIBRARY
────────────────────────────────────
from new import AdvancedBusinessScraper

scraper = AdvancedBusinessScraper()
business_data = scraper.scrape_website(url)
scraper.close()

⚙️ CONFIGURATION OPTIONS
═══════════════════════════════════════════════════════════════════════════════

All in config.py - easily customizable:

SCRAPING BEHAVIOR:
   MAX_PAGES_TO_SCRAPE = 10       # How many pages to crawl
   MAX_PRICING_CARDS = 10          # Max pricing plans to extract
   MAX_FEATURES = 30               # Max features per page
   MAX_INTEGRATIONS = 20           # Max partners to find

SELENIUM SETTINGS:
   WAIT_TIMEOUT = 15               # Page load timeout (seconds)
   SCROLL_DELAY = 0.5              # Delay between scrolls (seconds)

FILTERING & KEYWORDS:
   JUNK_KEYWORDS = [...]           # Pages to skip
   CTA_KEYWORDS = [...]            # What's a call-to-action
   CERT_KEYWORDS = [...]           # What's a certification

   3. Integrate in scraper.py
